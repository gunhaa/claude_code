# 코드 스타일 규칙

---

## 포맷터 & 린터 설정

```bash
# 포맷터 실행
# <명령어 작성 — 예: prettier --write . / black . / gofmt -w .>

# 린터 실행
# <명령어 작성 — 예: eslint . / flake8 / golangci-lint run>

# 저장 시 자동 포맷: IDE 설정 또는 PostToolUse Hook 활용
```

도구:
- 포맷터:  (예: Prettier, Black, gofmt)
- 린터:  (예: ESLint, Flake8, golangci-lint)
- 타입 체커:  (예: tsc, mypy, pyright)

---

## 들여쓰기 & 줄 길이

- 들여쓰기:  (예: 스페이스 2칸 / 4칸 / 탭)
- 최대 줄 길이:  (예: 100자)
- 문자열 따옴표:  (예: 싱글 / 더블 / 백틱)

## 네이밍 컨벤션

| 대상 | 규칙 | 예시 |
|------|------|------|
| 변수·함수 |  | `getUserById` / `user_name` |
| 클래스·타입 |  | `UserService` / `AuthToken` |
| 상수 |  | `MAX_RETRY_COUNT` |
| 파일명 |  | `user-service.ts` / `user_service.py` |
| 디렉토리 |  | `src/auth/` |

## 함수·클래스 작성 기준

- 함수는 **단일 책임** — 하나의 일만 한다.
- 함수 길이 권장 상한:  (예: 50줄)
- 매개변수 개수 권장 상한:  (예: 4개. 초과 시 객체로 묶기)
- 중첩 깊이 권장 상한:  (예: 3단계. 초과 시 early return 또는 함수 분리)

---

## 주석 작성 기준

- **WHY** 는 주석으로. **WHAT** 은 코드로 설명한다.
- 주석이 없어도 이해되는 코드를 목표로 한다.
- TODO 형식: `// TODO(이름): 설명 — 기한 or 이슈번호`
- 오래된 주석(dead comment)은 삭제한다.

**주석을 쓰는 경우:**
- 숨겨진 제약 조건 또는 외부 버그 우회
- 비직관적인 알고리즘의 의도
- 특정 방식을 *선택하지 않은* 이유

---

## 임포트 정렬

```
1. 표준 라이브러리
2. 서드파티 패키지
3. 내부 모듈 (절대 경로)
4. 내부 모듈 (상대 경로)
```

그룹 간 빈 줄 한 줄로 구분.

---

## 에러 처리

- 에러는 숨기지 않는다. `catch (e) {}` / `except: pass` 금지.
- 에러 메시지에는 컨텍스트를 포함한다: 어디서, 왜 실패했는지.
- 예외는 구체적인 타입으로 처리한다. 범용 `Exception` 남용 금지.

---

## 금지 패턴

- 매직 넘버·매직 문자열 — 상수로 분리
- 중복 코드 3회 이상 — 함수·모듈로 추출
- 전역 변수 남용
- 빈 catch 블록
