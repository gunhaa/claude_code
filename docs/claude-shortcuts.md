# Claude Code 단축키 & 슬래시 명령어

---

## 키보드 단축키

| 단축키 | 동작 |
|--------|------|
| `Shift + Tab` | Plan Mode ↔ Accept Mode 전환 |
| `Escape` | 현재 작업 즉시 중단 |
| `Escape × 2` | 입력창에 텍스트가 있으면 삭제 / 비어 있으면 이전 입력 복원 |
| `! + 명령어` | 대화를 끊지 않고 bash 명령 바로 실행 (`!git status`) |

**Plan Mode 활용 이유**

- 코드를 생성하기 전에 방향을 확인해 불필요한 토큰 소모를 방지합니다.
- 어떤 파일을 수정할지 미리 확인해 의도치 않은 사이드 이펙트를 줄입니다.
- 계획 확정 후 Accept Mode로 전환하면 됩니다.

## 슬래시 명령어

### 컨텍스트 관리

| 명령어 | 설명 |
|--------|------|
| `/clear` | 컨텍스트 완전 초기화. 새 작업 시작 시 사용. |
| `/compact` | 대화 내용 압축. 맥락은 유지하면서 토큰만 줄임. |
| `/context` | 현재 토큰 사용량 확인. 80% 이상이면 정리 시점. |

### 모델 & 세션

| 명령어 | 설명 |
|--------|------|
| `/models` | 모델 전환 (Opus · Sonnet · Haiku) |
| `/resume` | 이전 세션 복구 |
| `/fast` | Fast Mode 토글 (Opus 기반 빠른 출력) |

### 도구 & 기타

| 명령어 | 설명 |
|--------|------|
| `/mcp` | MCP 도구 관리. 안 쓰는 MCP는 비활성화해 토큰 절약. |
| `/memory` | 자동 메모리 확인 및 편집 |
| `/voice` | 음성 입력 모드 (Push-to-talk, 스페이스바) |
| `/export` | 현재 대화 내보내기 (다른 AI에 비평 요청 시 유용) |
| `/config` | 설정 변경 |
| `/init` | CLAUDE.md 자동 생성 |
| `/agents` | Sub-Agent 생성 및 관리 |
| `/help` | 내장 도움말 |

## 커스텀 슬래시 명령어 만들기

`.claude/commands/` 폴더에 `.md` 파일을 만들면 파일 이름이 곧 슬래시 명령어가 됩니다.

```
.claude/
  commands/
    review-pr.md     →  /review-pr
    deploy-staging.md  →  /deploy-staging
```

CLAUDE.md 트리거 키워드와 달리 **탭 자동완성**이 되고 Claude Code가 구조적으로 인식합니다.

## 입력 팁

- **스크린샷 드래그 앤 드롭**: 터미널에 이미지를 끌어다 놓으면 Claude가 인식합니다.  
  이미지만 던지지 말고 "무엇인지 + 어떻게 할지"를 함께 설명하세요.
- **iTerm 패널 분할**: `Cmd+D` (세로) / `Cmd+Shift+D` (가로) / `Cmd+[` `Cmd+]` (이동)
