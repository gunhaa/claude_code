다음 프로젝트 시작 전에 반드시 읽어볼 것.

## CLAUDE.md 작성

- **README.md는 Claude가 자동으로 읽지 않는다.**  
  AI 지침은 반드시 CLAUDE.md에 써야 효과가 있음.

- **지침은 구체적인 명령어로 써야 한다.**  
  "잘 해라" 같은 추상적인 표현은 효과 없음.  
  → `npm test && npm run lint`처럼 실행 가능한 형태로.

- **금지 사항은 "절대 하지 말 것"으로 명시해야 강하게 작동한다.**  
  "가능하면 피해라"는 예외를 허용하는 표현으로 받아들여짐.

- **이유(Why)를 함께 쓰면 예외 상황 대응이 좋아진다.**  
  Claude가 맥락을 이해하면 예외 상황에서 더 나은 판단을 함.

## CLAUDE.md 구조

- **200줄을 넘기면 지침 준수율이 떨어진다.**  
  초과 시 `.claude/rules/` 하위 파일로 분리하고 주제별로 쪼갤 것.

- **하위 디렉토리의 CLAUDE.md는 지연 로드(lazy load)된다.**  
  세션 시작 시 일괄 로드되지 않고, 해당 폴더 파일을 읽는 시점에 로드됨.

- **`.claude/` 폴더는 기본적으로 .gitignore에 추가되어 있을 수 있다.**  
  보일러플레이트처럼 rules/ 파일을 공유해야 한다면 .gitignore에 예외 추가 필요:  
  ```
  !boilerplate/.claude/
  !boilerplate/.claude/**
  ```

## 컨텍스트 관리

- **gitStatus는 세션 시작 시점의 스냅샷이다.**  
  대화 중 변경된 git 상태는 반영되지 않으므로 `git status`를 직접 실행해야 함.

- **MEMORY.md는 200줄 이후가 잘린다.**  
  장기 기억이 많아지면 오래된 것부터 정리할 것.

- **확실하지 않은 내용은 WebSearch로 검색 후 대답하게 해야 정확도가 높아진다.**  
  CLAUDE.md에 "확실하지 않은 것은 반드시 검색 후 대답해줘" 지침 추가 권장.

```

```
